วิธีใช้บน iPad / iPhone

  1. ใน Shopee หรือ TikTok กด Share แล้วเลือก Copy Link
  2. กลับมาที่ Flow Maker แล้วกด “วางจาก Clipboard”
  3. กด “สร้าง Storyboard”
  4. กด “คัดลอก Prompt” แล้ว “เปิด Google Flow”
  5. ใส่ภาพสินค้าจริงเป็น reference ใน Flow แล้ววาง Prompt
  6. ตรวจสินค้าให้ถูกต้องก่อนกด Generate
เพิ่มเป็นแอปบน iPad/iPhone: เปิดหน้านี้ใน Safari → Share → Add to Home Screen
